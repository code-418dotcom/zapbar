# Zapbar Plan 2: Expo App (Remote, Setup, Settings) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working Android app, `apps/remote`. It finds the soundbar on Wi-Fi, walks the user through labelling the HDMI inputs, and shows a one-screen remote: inputs, volume, sound row, Quick Selects, EQ sheet and now-playing. A settings area handles devices and input labels. All of it runs on `@zapbar/heos-core`.

**Architecture:**
- Expo SDK 58 app in the existing pnpm workspace, using Expo Router.
- React Native I/O is injected into heos-core: `react-native-tcp-socket` for the CLI, `fetch` for UPnP, and a small local Kotlin Expo module for SSDP discovery (MulticastLock and UDP multicast).
- A `DeviceManager` owns the heos-core store, the `HeosDevice` instances, device memory (labels and known devices in `expo-sqlite/kv-store`), and app lifecycle and network hooks.
- Screens are thin wrappers around pure view components that take props, so the UI is tested with React Native Testing Library without native code.

**Tech Stack:**
- Expo SDK 58 (React Native 0.88), Expo Router, TypeScript.
- Libraries: react-native-tcp-socket, expo-sqlite (kv-store), @react-native-community/netinfo, @react-native-community/slider, @expo/vector-icons, zustand.
- Tests: Jest (jest-expo) and @testing-library/react-native.
- Android release APK built locally with Gradle on the dev machine (`~/android-sdk`, JDK 17 at `~/tools/jdk-17.0.13+11`).

**Spec:** `docs/specs/2026-10-16-zapbar-design.md`, plus the device facts in `docs/probe-results.md`.

## Global Constraints

- **One-tap input switching, from any state.** From any state, including a stream such as Spotify playing, one tap on an input tile calls `playInput(mid)`. Input tiles are always rendered on the remote screen, whatever is playing. The now-playing strip sits above them and never replaces, covers or collapses them. This is the owner's explicit requirement (2026-10-16); Task 1 and Task 8 test it.
- **Android package id is `app.zapbar.remote`.** It is permanent once published.
- **Brand and wording.** The app name is "Zapbar". "HEOS" and "Denon" never appear in the app name or the UI chrome. They may appear only in the About disclaimer: "Zapbar is not affiliated with Denon or HEOS."
- **Network scope.** The app talks only to LAN devices, through heos-core. Plan 2 adds no analytics, crash reporting or third-party SDKs that phone home. The "Open Spotify" button hands off to the Spotify app with `Linking`; Zapbar itself makes no request to Spotify.
- **No dev servers.** No Metro or other server is exposed on the network. On-device testing uses a self-contained **release** APK signed with the debug key, so no port allocation is needed.
- **Colors are tokens in `src/theme.ts`.** Dark-first. Material You dynamic color is deferred to Plan 4 polish (ruling: it adds a native dependency for no Plan 2 behavior).
- **Visual rules.** Tap targets are at least 48 dp. Text on the accent background uses `colors.accentText`.

## Review Focus

1. **App resumed or recreated rapidly** (StrictMode double effects, AppState flapping between active and background). Expect exactly one live CLI connection, never two. Task 6 test: "rapid foreground flapping keeps one connection".
2. **Phone on mobile data or guest Wi-Fi.** Expect a "Connect to your home Wi-Fi" banner and no reconnect attempt while off the LAN. Task 6 test: "leaving the LAN does not force a reconnect"; Task 7 test: "bannerFor prefers the LAN message".
3. **The soundbar got a new DHCP address since the last launch.** Expect the stored IP to fail, discovery to find the device by serial, the remote to connect, and the new IP to be saved. Task 6 test: "a changed IP is rediscovered and saved".
4. **Very long input labels.** Expect tile labels to truncate to one line and never break the grid. Task 7 test: "long labels truncate to one line".
5. **Setup finds nothing, or the typed IP is malformed or not HEOS.** Expect the manual-IP step with a specific error, never an endless spinner. Task 9 tests: "no devices found → manual step", "malformed IP", "non-HEOS IP".

```ts
import TcpSocket from 'react-native-tcp-socket';
import type { HttpFn, LineSocket, SocketFactory } from '@zapbar/heos-core';

export const rnSocketFactory: SocketFactory = (host, port) =>
  new Promise((resolve, reject) => {
    const lineCbs: Array<(l: string) => void> = [];
    const closeCbs: Array<(e?: Error) => void> = [];
    let buf = '';
    let connected = false;
    let closed = false;
    let lastError: Error | undefined;
    const fireClose = () => {
      if (closed) return;
      closed = true;
      closeCbs.forEach((cb) => cb(lastError));
    };
    const timer = setTimeout(() => {
      if (connected) return;
      lastError = new Error('connect timeout');
      sock.destroy();
      reject(lastError);
    }, 3000);
    const sock = TcpSocket.createConnection({ host, port }, () => {
      connected = true;
      clearTimeout(timer);
      resolve(api);
    });
    const api: LineSocket = {
      write: (line) => {
        if (!closed) sock.write(line);
      },
      onLine: (cb) => {
        lineCbs.push(cb);
      },
      onClose: (cb) => {
        closeCbs.push(cb);
      },
      close: () => {
        sock.destroy();
        fireClose();
      },
    };
    sock.setEncoding('utf8');
    sock.on('data', (chunk: unknown) => {
      buf += String(chunk);
      let i: number;
      while ((i = buf.indexOf('\n')) !== -1) {
        const line = buf.slice(0, i).replace(/\r$/, '');
        buf = buf.slice(i + 1);
        if (line.trim()) lineCbs.forEach((cb) => cb(line));
      }
    });
    sock.on('error', (e: Error) => {
      lastError = e;
      if (!connected) {
        clearTimeout(timer);
        reject(e);
      }
    });
    sock.on('close', fireClose);
  });

// Hermes has no AbortSignal.timeout; build the timeout by hand.
export const rnHttp: HttpFn = async (url, req) => {
  const ac = new AbortController();
  const t = setTimeout(() => ac.abort(), req.timeoutMs);
  try {
    const res = await fetch(url, { method: req.method, headers: req.headers, body: req.body, signal: ac.signal });
    return { status: res.status, text: await res.text() };
  } finally {
    clearTimeout(t);
  }
};
```

```kotlin
package expo.modules.zapbardiscovery

import android.content.Context
import android.net.wifi.WifiManager
import expo.modules.kotlin.modules.Module
import expo.modules.kotlin.modules.ModuleDefinition
import java.net.DatagramPacket
import java.net.DatagramSocket
import java.net.InetAddress
import java.net.SocketTimeoutException

// SSDP M-SEARCH over UDP multicast. Android drops inbound multicast replies unless a
// MulticastLock is held, so the lock spans the whole search.
class ZapbarDiscoveryModule : Module() {
  override fun definition() = ModuleDefinition {
    Name("ZapbarDiscovery")

    AsyncFunction("searchAsync") { message: String, timeoutMs: Int ->
      val context = appContext.reactContext ?: throw IllegalStateException("No Android context")
      val wifi = context.applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager
      val lock = wifi.createMulticastLock("zapbar-ssdp").apply {
        setReferenceCounted(false)
        acquire()
      }
      val replies = mutableListOf<Map<String, String>>()
      try {
        DatagramSocket().use { socket ->
```

```ts
export function arrangeInputs(inputs: InputSource[], prefs: InputPrefs): { all: ArrangedInput[]; visible: ArrangedInput[]; hidden: ArrangedInput[] } {
  const rows = inputs.map((input, index) => {
    const p = prefs[input.mid] ?? {};
    return {
      mid: input.mid,
      label: p.label?.trim() || defaultLabel(input),
      icon: p.icon && p.icon in ICONS ? p.icon : defaultIcon(input.mid),
      hidden: p.hidden ?? false,
      order: p.order ?? index,
    };
  });
  rows.sort((a, b) => a.order - b.order);
  const all: ArrangedInput[] = rows.map(({ order: _order, ...r }) => r);
  return { all, visible: all.filter((r) => !r.hidden), hidden: all.filter((r) => r.hidden) };
}

  const i = mids.indexOf(mid);

  const next = [...mids];
  [next[i], next[j]] = [next[j]!, next[i]!];
  return next;
}
```

```ts
import type { IconId } from './inputs';

export interface KeyValue {
  getItemSync(key: string): string | null;
  setItemSync(key: string, value: string): void;
  removeItemSync(key: string): void;
}

export interface KnownDevice {
  key: string;
  name: string;
  model: string;
  lastIp: string;
}

export interface InputPref {
  label?: string;
  icon?: IconId;
  hidden?: boolean;
  order?: number;
}
export type InputPrefs = Record<string, InputPref>;

const K = {
  devices: 'devices',
  active: 'active',
  prefs: (key: string) => `prefs:${key}`,
  setup: (key: string) => `setup:${key}`,
};

/** Device memory keyed by serial, so labels survive IP changes. */
export class DeviceMemory {
  constructor(private readonly kv: KeyValue) {}

  private read<T>(key: string, fallback: T): T {
    const raw = this.kv.getItemSync(key);
    if (!raw) return fallback;
    try {
      return JSON.parse(raw) as T;
    } catch {
      return fallback;
    }
  }

  private write(key: string, value: unknown): void {
    this.kv.setItemSync(key, JSON.stringify(value));
  }

  devices(): KnownDevice[] {
    const list = this.read<KnownDevice[]>(K.devices, []);
    return Array.isArray(list) ? list : [];
  }

  saveDevice(d: KnownDevice): void {
    const list = this.devices();
    const i = list.findIndex((x) => x.key === d.key);
    if (i === -1) list.push(d);
    else list[i] = d;
    this.write(K.devices, list);
  }

  forgetDevice(key: string): void {
    this.write(K.devices, this.devices().filter((d) => d.key !== key));
    this.kv.removeItemSync(K.prefs(key));
    this.kv.removeItemSync(K.setup(key));
    if (this.read<string | null>(K.active, null) === key) this.kv.removeItemSync(K.active);
  }

  activeKey(): string | null {
    const list = this.devices();
    const stored = this.read<string | null>(K.active, null);
    if (stored && list.some((d) => d.key === stored)) return stored;
    return list[0]?.key ?? null;
  }

  setActive(key: string): void {
    this.write(K.active, key);
  }

  inputPrefs(key: string): InputPrefs {
    return this.read<InputPrefs>(K.prefs(key), {});
  }

  setInputPref(key: string, mid: string, patch: InputPref): InputPrefs {
    const all = this.inputPrefs(key);
    const next = { ...all, [mid]: { ...all[mid], ...patch } };
    this.write(K.prefs(key), next);
    return next;
  }

  setInputOrder(key: string, mids: string[]): InputPrefs {
    const all = this.inputPrefs(key);
    const next: InputPrefs = { ...all };
    mids.forEach((mid, order) => {
      next[mid] = { ...next[mid], order };
    });
    this.write(K.prefs(key), next);
    return next;
  }

  isSetupDone(key: string): boolean {
    return this.read<boolean>(K.setup(key), false) === true;
  }

  markSetupDone(key: string): void {
    this.write(K.setup(key), true);
  }
}

export function memoryKv(): KeyValue {
  const m = new Map<string, string>();
  return {
    getItemSync: (k) => m.get(k) ?? null,
    setItemSync: (k, v) => {
      m.set(k, v);
    },
    removeItemSync: (k) => {
      m.delete(k);
    },
  };
}

/** expo-sqlite's synchronous key-value store; loaded lazily so tests never touch native code. */
export function sqliteKv(): KeyValue {
  return require('expo-sqlite/kv-store').default as KeyValue;
}
```

```ts
import {
  createHeosStore,
  findIpByKey,
  HeosDevice,
  listPlayers,
  type Capabilities,
  type DeviceOptions,
  type FoundPlayer,
  type HttpFn,
  type SocketFactory,
} from '@zapbar/heos-core';
import { createStore } from 'zustand/vanilla';
import type { DeviceMemory, InputPref, InputPrefs, KnownDevice } from './memory';

export interface UiState {
  activeKey: string | null;
  devices: KnownDevice[];
  prefs: Record<string, InputPrefs>;
  onLan: boolean;
}

export interface ManagerDeps {
  socketFactory: SocketFactory;
  http: HttpFn;
  memory: DeviceMemory;
  discover: () => Promise<string[]>;
  deviceOptions?: Partial<Omit<DeviceOptions, 'socketFactory' | 'http' | 'store' | 'resolveIp'>>;
}

export class DeviceManager {
  readonly store = createHeosStore();
  readonly ui;
  private devices = new Map<string, HeosDevice>();
  private foreground = true;

  constructor(private readonly d: ManagerDeps) {
    const known = d.memory.devices();
    this.ui = createStore<UiState>()(() => ({
      activeKey: d.memory.activeKey(),
      devices: known,
      prefs: Object.fromEntries(known.map((k) => [k.key, d.memory.inputPrefs(k.key)])),
      onLan: true,
    }));
    // Persist IP changes found by re-discovery so the next launch connects directly.
    this.store.subscribe((s) => {
      for (const known of this.ui.getState().devices) {
        const ip = s.devices[known.key]?.ip;
        if (ip && ip !== known.lastIp) this.saveKnown({ ...known, lastIp: ip });
      }
    });
  }

  start(): void {
    const key = this.ui.getState().activeKey;
    if (key) this.activate(key);
  }

  stopAll(): void {
    for (const dev of this.devices.values()) dev.stop();
  }

  device(key: string): HeosDevice | undefined {
    return this.devices.get(key);
  }

  get active(): HeosDevice | undefined {
    const key = this.ui.getState().activeKey;
    return key ? this.devices.get(key) : undefined;
  }

  async scan(): Promise<FoundPlayer[]> {
    return listPlayers(await this.d.discover(), this.d.socketFactory, this.d.deviceOptions?.cliPort);
  }

  probeIp(ip: string): Promise<FoundPlayer[]> {
    return listPlayers([ip], this.d.socketFactory, this.d.deviceOptions?.cliPort);
  }

  adopt(p: FoundPlayer): void {
    this.saveKnown({ key: p.key, name: p.name, model: p.model, lastIp: p.ip });
    this.activate(p.key);
  }

  activate(key: string): void {
    const known = this.ui.getState().devices.find((k) => k.key === key);
    if (!known) return;
    for (const [other, dev] of this.devices) if (other !== key) dev.stop();
    let dev = this.devices.get(key);
    if (!dev) {
      dev = new HeosDevice(
        { ...this.d.deviceOptions, socketFactory: this.d.socketFactory, http: this.d.http, store: this.store, resolveIp: (k) => this.resolveIp(k) },
        { key, ip: known.lastIp },
      );
      this.devices.set(key, dev);
    }
    this.d.memory.setActive(key);
    this.ui.setState({ activeKey: key });
    dev.start();
    dev.setVisible(this.foreground);
  }

  forget(key: string): void {
    this.devices.get(key)?.stop();
    this.devices.delete(key);
    this.d.memory.forgetDevice(key);
    const { [key]: _gone, ...prefs } = this.ui.getState().prefs;
    this.ui.setState({ devices: this.d.memory.devices(), prefs, activeKey: this.d.memory.activeKey() });
    const next = this.ui.getState().activeKey;
    if (next) this.activate(next);
  }

  waitForCaps(key: string, timeoutMs: number): Promise<Capabilities | null> {
    const check = () => {
      const s = this.store.getState().devices[key];
      return s && (s.status === 'ready' || s.status === 'degraded') && s.caps ? s.caps : null;
    };
    return new Promise((resolve) => {
      const now = check();
      if (now) return resolve(now);
      const timer = setTimeout(() => {
        unsub();
        resolve(null);
      }, timeoutMs);
      const unsub = this.store.subscribe(() => {
        const caps = check();
        if (!caps) return;
        clearTimeout(timer);
        unsub();
        resolve(caps);
      });
    });
  }

  setInputPref(mid: string, patch: InputPref): void {
    const key = this.ui.getState().activeKey;
    if (!key) return;
    const next = this.d.memory.setInputPref(key, mid, patch);
    this.ui.setState((s) => ({ prefs: { ...s.prefs, [key]: next } }));
  }

  setInputOrder(mids: string[]): void {
    const key = this.ui.getState().activeKey;
    if (!key) return;
    const next = this.d.memory.setInputOrder(key, mids);
    this.ui.setState((s) => ({ prefs: { ...s.prefs, [key]: next } }));
  }

  isSetupDone(key: string): boolean {
    return this.d.memory.isSetupDone(key);
  }

  markSetupDone(key: string): void {
    this.d.memory.markSetupDone(key);
  }

  /** App to the foreground: poll UPnP settings and force a fresh connection (spec §5). */
  setForeground(fg: boolean): void {
    this.foreground = fg;
    const dev = this.active;
    if (!dev) return;
    dev.setVisible(fg);
    if (fg) dev.reconnectNow();
  }

  /** Off the LAN nothing can connect; reconnect at once when the LAN comes back. */
  setNetwork(onLan: boolean): void {
    const was = this.ui.getState().onLan;
    this.ui.setState({ onLan });
    if (onLan && !was) this.active?.reconnectNow();
  }

  private async resolveIp(key: string): Promise<string | null> {
    return findIpByKey(await this.d.discover(), key, this.d.socketFactory, this.d.deviceOptions?.cliPort);
  }

  private saveKnown(k: KnownDevice): void {
    this.d.memory.saveDevice(k);
    this.ui.setState((s) => ({
      devices: this.d.memory.devices(),
      prefs: { ...s.prefs, [k.key]: s.prefs[k.key] ?? this.d.memory.inputPrefs(k.key) },
    }));
  }
}
```

```tsx
import { AppState } from 'react-native';

import { discoverIps, nativeSearch } from './discovery';
import { DeviceManager, type UiState } from './manager';
import { DeviceMemory, sqliteKv } from './memory';
import { rnHttp, rnSocketFactory } from './transport';

const Ctx = createContext<DeviceManager | null>(null);

export const isLan = (n: { type: string; isConnected: boolean | null }) =>
  !!n.isConnected && (n.type === 'wifi' || n.type === 'ethernet');

function createDefaultManager(): DeviceManager {
  const search = nativeSearch();
  return new DeviceManager({
    socketFactory: rnSocketFactory,
    http: rnHttp,
    memory: new DeviceMemory(sqliteKv()),
    discover: () => discoverIps(search),
  });
}

export function RuntimeProvider({ manager, children }: { manager?: DeviceManager; children: ReactNode }) {
  const [m] = useState(() => manager ?? createDefaultManager());
  useEffect(() => {
    m.start();
    const app = AppState.addEventListener('change', (s) => m.setForeground(s === 'active'));
    const unsubNet = NetInfo.addEventListener((n) => m.setNetwork(isLan(n)));
    return () => {
      app.remove();
      unsubNet();
      m.stopAll();
    };
  }, [m]);
  return <Ctx.Provider value={m}>{children}</Ctx.Provider>;
}

export function useManager(): DeviceManager {
  const m = useContext(Ctx);
  if (!m) throw new Error('RuntimeProvider missing');
  return m;
}

export function useUi<T>(selector: (s: UiState) => T): T {
  return useStore(useManager().ui, selector);
}

export function useActiveDevice(): DeviceState | null {
  const m = useManager();
  const key = useUi((s) => s.activeKey);
  return useStore(m.store, (s) => (key ? s.devices[key] ?? null : null));
}
```

```tsx
import { Pressable, StyleSheet, Text, View } from 'react-native';
import { ICONS, type ArrangedInput } from '../runtime/inputs';
import { colors, radius, space } from '../theme';

interface Props {
  inputs: ArrangedInput[];
  hiddenCount: number;
  active: string | null;
  disabled: boolean;
  onSelect(mid: string): void;
  onEdit(mid: string): void;
  onShowHidden(): void;

export function InputGrid({ inputs, hiddenCount, active, disabled, onSelect, onEdit, onShowHidden }: Props) {
  return (
    <View style={s.grid}>
      {inputs.map((i) => {
        const on = i.mid === active;
        return (
          <Pressable
            key={i.mid}
            testID={`input-${i.mid}`}
            accessibilityRole="button"
            accessibilityLabel={i.label}
            accessibilityState={{ selected: on, disabled }}
            disabled={disabled}
            onPress={() => onSelect(i.mid)}
            onLongPress={() => onEdit(i.mid)}
            style={({ pressed }) => [s.tile, on && s.active, pressed && s.pressed, disabled && s.disabled]}
          >
            <MaterialCommunityIcons name={ICONS[i.icon]} size={26} color={on ? colors.accentText : colors.text} />
            <Text numberOfLines={1} style={[s.label, on && s.activeLabel]}>
              {i.label}
            </Text>
          </Pressable>
        );
      })}
      {hiddenCount > 0 && (
        <Pressable onPress={onShowHidden} style={s.more} accessibilityRole="button">
          <Text style={s.moreText}>+{hiddenCount} hidden</Text>
        </Pressable>
      )}
    </View>
  );
}
```

```ts
import type { FoundPlayer, InputSource } from '@zapbar/heos-core';
import { createStore } from 'zustand/vanilla';
import { extraInputs, labelQueue, prefFromChoice, type ChoiceId } from '../runtime/inputs';
import type { DeviceManager } from '../runtime/manager';

export type SetupStep =
  | { kind: 'scanning' }
  | { kind: 'pick'; players: FoundPlayer[] }
  | { kind: 'manual'; error: string | null }
  | { kind: 'connecting'; name: string }
  | { kind: 'label'; input: InputSource; index: number; total: number }
  | { kind: 'extras'; inputs: InputSource[] }
  | { kind: 'done' };

export type SetupManager = Pick<DeviceManager, 'scan' | 'probeIp' | 'adopt' | 'waitForCaps' | 'setInputPref' | 'markSetupDone'>;

const IPV4 = /^(25[0-5]|2[0-4]\d|1?\d?\d)(\.(25[0-5]|2[0-4]\d|1?\d?\d)){3}$/;

export class SetupFlow {
  readonly state = createStore<{ step: SetupStep }>()(() => ({ step: { kind: 'scanning' } as SetupStep }));
  private key: string | null = null;
  private queue: InputSource[] = [];
  private extras: InputSource[] = [];
  private index = 0;

  constructor(private readonly m: SetupManager) {}

  private set(step: SetupStep): void {
    this.state.setState({ step });
  }

  async scan(): Promise<void> {
    this.set({ kind: 'scanning' });
    const players = await this.m.scan().catch(() => [] as FoundPlayer[]);
    await this.offer(players, { kind: 'manual', error: null });
  }

  async manual(raw: string): Promise<void> {
    const ip = raw.trim();
    if (!IPV4.test(ip)) return this.set({ kind: 'manual', error: 'Enter an IP address like 192.168.1.20' });
    this.set({ kind: 'scanning' });
    const players = await this.m.probeIp(ip).catch(() => [] as FoundPlayer[]);
    await this.offer(players, { kind: 'manual', error: `No soundbar answered at ${ip}` });
  }

  private async offer(players: FoundPlayer[], none: SetupStep): Promise<void> {
    if (players.length === 0) return this.set(none);
    if (players.length === 1) return this.choose(players[0]!);
    this.set({ kind: 'pick', players });
  }

  async choose(p: FoundPlayer): Promise<void> {
    this.set({ kind: 'connecting', name: p.name });
    this.m.adopt(p);
    const caps = await this.m.waitForCaps(p.key, 10_000);
    if (!caps) return this.set({ kind: 'manual', error: `Couldn't connect to ${p.name}` });
    this.key = p.key;
    this.queue = labelQueue(caps.inputs);
    this.extras = extraInputs(caps.inputs);
    this.index = 0;
    this.next();
  }

  answer(id: ChoiceId): void {
    const input = this.queue[this.index];
    if (!input) return;
    this.m.setInputPref(input.mid, prefFromChoice(id));
    this.index++;
    this.next();
  }

  finishExtras(usedMids: string[]): void {
    for (const i of this.extras) this.m.setInputPref(i.mid, { hidden: !usedMids.includes(i.mid) });
    if (this.key) this.m.markSetupDone(this.key);
    this.set({ kind: 'done' });
  }

  private next(): void {
    const input = this.queue[this.index];
    if (input) return this.set({ kind: 'label', input, index: this.index, total: this.queue.length });
    if (this.extras.length) return this.set({ kind: 'extras', inputs: this.extras });
    this.finishExtras([]);
  }
}
```

```tsx
import { MaterialCommunityIcons } from '@expo/vector-icons';
import { Pressable, ScrollView, StyleSheet, Switch, Text, TextInput, View } from 'react-native';
import { ICONS, type ArrangedInput, type IconId } from '../runtime/inputs';
import { colors, radius, space } from '../theme';

interface Props {
  inputs: ArrangedInput[];
  focus?: string;
  onRename(mid: string, label: string): void;
  onIcon(mid: string, icon: IconId): void;
  onHidden(mid: string, hidden: boolean): void;
  onMove(mid: string, delta: -1 | 1): void;
}

const ICON_IDS = Object.keys(ICONS) as IconId[];

export function InputsEditor({ inputs, focus, onRename, onIcon, onHidden, onMove }: Props) {
  return (
    <ScrollView contentContainerStyle={s.content}>
      {inputs.map((i, idx) => (
        <View key={i.mid} style={[s.card, i.mid === focus && s.focus]}>
          <View style={s.head}>
            <TextInput
              accessibilityLabel={`Label for ${i.label}`}
              defaultValue={i.label}
              onEndEditing={(e) => onRename(i.mid, e.nativeEvent.text)}
              autoFocus={i.mid === focus}
              style={s.input}
            />
            <Switch
              accessibilityLabel={`Show ${i.label}`}
              value={!i.hidden}
              onValueChange={(show) => onHidden(i.mid, !show)}
              trackColor={{ true: colors.accent, false: colors.border }}
            />
          </View>
          <View style={s.icons}>
            {ICON_IDS.map((id) => (
              <Pressable key={id} accessibilityRole="button" accessibilityLabel={`Icon ${id}`} accessibilityState={{ selected: i.icon === id }} onPress={() => onIcon(i.mid, id)} style={[s.iconBtn, i.icon === id && s.iconOn]}>
                <MaterialCommunityIcons name={ICONS[id]} size={22} color={i.icon === id ? colors.accentText : colors.text} />
              </Pressable>
            ))}
          </View>
          <View style={s.move}>
            <Pressable accessibilityRole="button" accessibilityLabel={`Move ${i.label} up`} disabled={idx === 0} onPress={() => onMove(i.mid, -1)} style={s.iconBtn}>
              <MaterialCommunityIcons name="chevron-up" size={22} color={idx === 0 ? colors.border : colors.text} />
            </Pressable>
            <Pressable accessibilityRole="button" accessibilityLabel={`Move ${i.label} down`} disabled={idx === inputs.length - 1} onPress={() => onMove(i.mid, 1)} style={s.iconBtn}>
              <MaterialCommunityIcons name="chevron-down" size={22} color={idx === inputs.length - 1 ? colors.border : colors.text} />
            </Pressable>
          </View>
        </View>
      ))}
    </ScrollView>
  );
}

const s = StyleSheet.create({
  content: { padding: space(4), gap: space(3) },
  card: { backgroundColor: colors.surface, borderRadius: radius, padding: space(3), gap: space(3) },
```

```tsx
import { useLocalSearchParams } from 'expo-router';
import { SafeAreaView } from 'react-native-safe-area-context';
import { arrangeInputs, moveInput } from '../../src/runtime/inputs';
import { useActiveDevice, useManager, useUi } from '../../src/runtime/RuntimeProvider';
import { colors } from '../../src/theme';
import { InputsEditor } from '../../src/ui/InputsEditor';

export default function InputsScreen() {
  const m = useManager();
  const state = useActiveDevice();
  const prefs = useUi((s) => (state ? s.prefs[state.key] : undefined));
  const { focus } = useLocalSearchParams<{ focus?: string }>();
  const { all } = arrangeInputs(state?.caps?.inputs ?? [], prefs ?? {});
  return (
    <SafeAreaView style={{ flex: 1, backgroundColor: colors.bg }}>
      <InputsEditor
        inputs={all}
        focus={focus}
        onRename={(mid, label) => m.setInputPref(mid, { label: label.trim() || undefined })}
        onIcon={(mid, icon) => m.setInputPref(mid, { icon })}
        onHidden={(mid, hidden) => m.setInputPref(mid, { hidden })}
        onMove={(mid, delta) => m.setInputOrder(moveInput(all.map((i) => i.mid), mid, delta))}
      />
    </SafeAreaView>
  );
}
```
